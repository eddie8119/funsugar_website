# SitePhoto｜拍攝須知雙 Tab 精簡執行計畫

## 1. 目標

將 `/sitephoto/term-of-service` 改為「拍攝須知與服務約定」，採 **公益攝影／一般付費攝影** 雙 Tab。內容對準有經驗的室內設計師，不羅列清潔、床單、鏡面、線材等瑣碎提醒，也不在此頁重複精修和交付的技術細節。

核心原則：**設計師負責空間與軟裝呈現；SitePhoto 負責攝影。** 公益案完全不向委託人收費，超出範圍的工作不以加價方式承接。

## 2. 同行參考與取捨

- 物室空間攝影：https://www.matteroom.studio/ —— 軟裝由設計師準備或另找軟裝公司。
- 嵐宇空間攝影：https://lanyuphoto.com.tw/space%E6%94%9D%E5%BD%B1%E6%96%B9%E6%A1%88/ —— 客戶自行處理軟裝，攝影師視構圖微調。
- FineStudio：https://www.finestudio.tw/tips/ —— Deco 由設計師／軟裝團隊負責，攝影師做必要的畫面調整。

採用同行的「責任界線明確、文字簡短」做法，不複製其收費、交通或取消條款。

## 3. 頁面結構

- H1：拍攝須知與服務約定
- 引言：為了讓攝影順利進行，請在申請前確認以下合作方式。
- Tab A：公益攝影（預設）
- Tab B：一般付費攝影
- 底部：返回 SitePhoto／申請委託 CTA

### Tab A｜公益攝影（建議正式文案）

**拍攝內容與軟裝分工**

SitePhoto 提供室內空間攝影，不包含軟裝設計、家具配置或現場佈置。請由設計師自行完成相關安排；如有需要，可另行委託專業軟裝團隊。

拍攝時，我會依構圖與光線需要，適度調整小型擺設，但不負責整體場景佈置。

**現場拍攝條件**

請確認案場已達適合拍攝的狀態，並完成進場及拍攝許可的協調。若現場尚未完成佈置、仍有施工干擾，或實際條件與事前確認有明顯落差，以致無法正常拍攝，我可以與委託人協調改期；若無法達成共識，得不執行當次拍攝。

為避免雙方耗費時間，若案場狀況有變，請儘早告知。

**公益委託與捐款**

公益攝影不收取任何攝影服務費，也不提供額外付費的軟裝或修圖服務。確認名額、拍攝範圍及日期後，委託人再依約定方案直接向公益機構捐款，款項不經 SitePhoto。

**改期與取消**

如需改期，請儘早聯繫協調。已完成的公益捐款並非支付給 SitePhoto 的攝影費，SitePhoto 無法代公益機構退款。若因 SitePhoto 的原因無法履行，應優先協調補拍或提出合理替代安排，不以本條款免除應負責任。

### Tab B｜一般付費攝影（建議正式文案）

**拍攝內容與軟裝分工**

SitePhoto 提供室內空間攝影，不包含軟裝設計、家具配置或現場佈置。請由委託人自行安排，或委託專業軟裝團隊。攝影時可依構圖需要適度微調小型擺設。

**拍攝安排**

拍攝範圍、日期、費用與其他特殊需求，於接受委託前個別確認。委託人應確保案場已適合拍攝，並完成進場許可協調；若現場條件與事前確認不符，雙方另行協商是否調整或改期。

**費用與變更**

依雙方確認的報價與付款約定辦理。任何超出原定拍攝範圍的需求，均應事先確認是否承接及相關費用。

## 4. 實作規格（Nuxt 2）

1. 保留既有路徑 `/sitephoto/term-of-service`，避免既有連結失效。
2. 使用 Vue 2 相容的雙 Tab 元件；預設 `公益攝影`。
3. Tab 按鈕使用可辨識的選取狀態、鍵盤操作與 `aria-selected`；切換後顯示對應文案。
4. 可用 `?type=charity` 與 `?type=paid` 預選 Tab；從申請表單依委託類型帶入連結。
5. 保留共用的標題與品牌視覺；不要為兩個 Tab 重複建立兩個頁面。
6. 將所有正式文字寫入頁面 HTML（SSR／靜態產出可讀），避免只在瀏覽器執行後才載入。
7. 表單確認勾選的文字使用「我已閱讀對應委託類型的拍攝須知與服務約定」，並連到相應 Tab。
8. 本頁 SEO Title 以「SitePhoto 拍攝須知與服務約定｜公益攝影・商業攝影」為主，不強行堆砌關鍵字。
